# Dokumentasi IT Development - UFOSI Project

Repository ini berisi dokumentasi bagian **IT Development** untuk proyek **UFOSI Project**.  
Dokumentasi ini disusun untuk menjelaskan peran, alur kerja, kesiapan operasional, serta hasil akhir dari sisi IT Development dalam pengembangan aplikasi.

---

## 1. Deskripsi Proyek

**UFOSI Project** merupakan proyek kolaboratif yang melibatkan beberapa role, seperti:

- IT Development
- IT Operations
- IT Security
- IT Risk Management
- UI/UX

Pada proyek ini, tim **IT Development** berfokus pada desain, pengembangan, serta testing aplikasi UFOSI.

---

## 2. Peran IT Development

Role **IT Development** mencakup hal mulai dari pengembangan sampai .

Beberapa tanggung jawab utama IT Development dalam proyek ini:

1. Membantu mendesain tampilan UI/UX aplikasi.
2. Mendesain database dan mendefinisikan fitur-fitur yang diperlukan.
3. Mengembangkan API AI.
4. Mengembangkan Frontend & Backend
5. Menulis dokumentasi API.
6. Melakukan testing aplikasi.
7. Mendokumentasikan hasil testing aplikasi
8. Melakukan building docker image untuk dideploy
9. Melakukan smoke test.
